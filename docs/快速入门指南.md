# BizPulse BI 智能平台 - 快速入门指南

## 项目概述

BizPulse 是基于 Claude Code 扩展体系构建的企业级 BI 数据架构与智能分析平台。

**核心能力**：
- 多 Agent 协同的 BI 业务智能中枢
- 支持 L2O/O2C/P2P 核心业务流程分析
- 自动化 DAX 代码生成与报表开发
- ETL 流程智能优化

## 快速开始

### 1. 环境准备

```bash
# Node.js >= 18
node --version

# Azure 订阅（可选，用于 MCP 集成）
# 需要配置以下环境变量
export AZURE_SUBSCRIPTION_ID=your-subscription-id
export AZURE_TENANT_ID=your-tenant-id
export AZURE_CLIENT_ID=your-client-id
export AZURE_CLIENT_SECRET=your-client-secret
```

### 2. 启动 Claude Code

```bash
# 进入项目目录
cd bizpulse

# 启动 Claude Code
claude
```

### 3. 基本使用

**场景 1：BI 业务流程分析**
```
用户: 分析 O2C 订单到回款流程的性能
```

**场景 2：DAX 代码生成**
```
用户: 生成应收账款账龄分析的 DAX 代码
```

**场景 3：数据模型设计**
```
用户: 设计销售主题的数据仓库模型
```

## 核心技能

### bi-workflow（BI 业务工作流）
协调多 Agent 完成端到端 BI 分析任务。

**触发条件**：
- L2O/O2C/P2P 业务流程分析
- BI 报表需求分析与设计
- 业务指标体系定义

### dax-generator（DAX 代码生成）
根据业务需求生成高质量 DAX 代码。

**触发条件**：
- Power BI DAX 公式编写
- 时间智能函数
- 财务/业务计算

### data-modeler（数据模型设计）
提供企业级数据建模支持。

**触发条件**：
- 数据仓库设计
- 维度建模
- ER 图生成

### etl-pipeline（ETL 流程构建）
设计、构建和优化 ETL 数据管道。

**触发条件**：
- ETL 流程设计
- Azure Data Factory 配置
- 数据同步策略

## 示例对话

### 示例 1：生成 O2C 账龄分析 DAX

## 故障排查

### Skill 未触发

检查 SKILL.md 中的 `trigger` 字段是否匹配用户输入。

### Agent 未调度

确认 Agent 文件在 `.claude/agents/` 目录下，frontmatter 配置正确。

### MCP 连接失败

1. 检查环境变量配置
2. 验证 Azure 服务认证
3. 确认网络连通性

## 扩展指南

### 添加新 Skill

1. 创建 `.claude/skills/[skill-name]/SKILL.md`
2. 定义 frontmatter 中的 `name` 和 `trigger`
3. 编写 Skill 内容和规则

### 添加新 Agent

1. 创建 `.claude/agents/[agent-name].md`
2. 定义 frontmatter（name, model, tools, color）
3. 编写 Agent 角色描述和工作流程

### 添加 MCP 服务器

1. 在 `src/mcp/` 下创建服务器目录
2. 实现 MCP 协议接口
3. 在 `.mcp.json` 中注册服务器
