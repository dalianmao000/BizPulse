## 集成测试

### IT-001: 端到端 O2C 分析流程

```
步骤：
1. 用户请求 O2C 账龄分析
2. bi-workflow skill 拦截请求
3. ProcessInsightAgent 分析数据
4. DAXBIAssistantAgent 生成 DAX
5. DocComplianceAgent 生成文档
6. 输出完整交付物

验收标准：
- 输出包含账龄分段 DAX
- 输出包含数据模型建议
- 输出包含使用指南
```

### IT-002: 端到端数据模型设计流程

```
步骤：
1. 用户请求销售主题数据模型
2. data-modeler skill 触发
3. DataArchAgent 输出模型设计
4. DAXBIAssistantAgent 生成相关度量值
5. DocComplianceAgent 生成文档

验收标准：
- 输出 Fact/Dim 表结构
- 输出 DDL 脚本
- 输出血缘关系
```
